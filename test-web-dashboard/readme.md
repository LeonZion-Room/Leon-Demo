# 具体需求
- 希望能完成一个 网页状态检测器，用于检测网页情况是否符合预期
- 基于 streamlit 实现前端
---
图片比较：
- 通过 test.py 的内容的方式实现 网页内容的截图
- 希望通过一个尽量简单的 opencv 方式实现差异程度比较，当相似程度>90% 认为是相同网页，认为是运行正常
---
检测逻辑：
- 通过 streamlit 有个检测任务创建的表单
- 创建时候需要输入一个网页，然后点击获取基准会自动获取一张当前截图，经用户确认无误后，认定为正常状态，然后点击确认创建检测单元
- 之后可以设置检测的时间间隔，设定每个检测单元过多久就自动获取一次截图并与正常状态的图片对比相似度，用于判断网页是否正常运行
